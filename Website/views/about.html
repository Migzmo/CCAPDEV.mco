About This Website

LaSapp is a web application designed to help users discover and explore restaurants. It provides a user-friendly interface for browsing restaurants by category, searching for specific cuisines, and saving favorite places for future visits.

NPM Packages Used

  • express-fileupload: Simple middleware for handling file uploads in Express applications.
  • mongoose: A MongoDB object modeling tool designed to work in an asynchronous environment.
