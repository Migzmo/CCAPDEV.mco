## 🔍 Overview
LaSapp is a web application that provides a comprehensive restaurant directory. Users can view restaurant information, leave reviews, and navigate through different restaurant pages. Here, users can:

- Browse restaurants by cuisine type  
- View detailed restaurant information  
- Create and manage user accounts  
- Leave and read reviews  
- Upload and manage restaurant profiles (for business owners)

---

## 🛠 Technology Stack

### Backend
- **Node.js** with **Express.js** framework  
- **MongoDB** with **Mongoose** ODM  
- **express-session** for user authentication  
- **bcrypt** for password hashing  
- **express-fileupload** for handling file uploads

### Frontend
- **Handlebars (HBS)** as the templating engine  
- **JavaScript** for client-side functionality  
- **CSS** for styling  
- **Google Fonts** for typography  
- **Material Symbols** for icons

## ✨ Features

### 👤 User Features
- User registration and authentication  
- Profile management with image upload  
- Restaurant browsing and filtering  
- Review submission and management  

### 🧑‍🍳 Business Owner Features
- Restaurant profile creation and management  
- Menu management  
- Response to customer reviews  
- Business analytics  

### ⚙️ Core Functionalities

- User session management  
- Responsive design  
- Search and filtering
